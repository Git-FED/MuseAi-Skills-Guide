# Posting Run Pre-Flight Checks

## Tag every destination by audience

- List every destination account for the run with its audience tag, for example work/tech, personal, or community. No account ships without a tag.
- Content must match its audience tag. Audiences never mix: work content never goes to a personal account, and personal content never goes to a work account.
- When a worker carries the run, the brief names each account and its tag, so the worker cannot choose a destination on its own.

## Verify each account and its scope

- Confirm each handle is the user's own account and matches its audience tag before anything posts. A handle that does not match stops the run.
- Check the user's standing rules before you pick destinations, such as groups-only versus profile posting. A missed scope rule can suspend the account.
- When a rule is new or unclear, post nothing and ask.

## Get the destination list approved

- Show the user the destination list itself for the specific run, with account and audience tag, as part of the approval. Copy approval covers the copy, not the destination.
- A changed caption, crop, audience, or destination needs fresh approval.

## Alternatives for better results

- Reuse one approved destination list across runs instead of rebuilding it, and retire handles the moment they leave the user's control.
