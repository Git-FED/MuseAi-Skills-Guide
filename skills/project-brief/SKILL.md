# Project Brief

Turn the idea into: target users, problem, proposed behavior, non-goals, constraints, acceptance criteria, risks, open questions, and a first milestone that can be completed and demonstrated quickly.

Keep the first milestone narrow. Prefer a working vertical slice over a large architecture. State what will not be built yet. Every acceptance criterion should be observable by a person running the project.
