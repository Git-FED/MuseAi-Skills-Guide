# Roadmap: what is next for Muse Skills Guide?

This issue is the public tracker for the repository roadmap. The shipped foundations are the usage-audit prompt, privacy-safe scaffold, accessible promotional page, live PWA demo, README media, and installable example skills.

## How to help

Comment with a concrete use case, a small reproducible improvement, or a proposed acceptance criterion. Keep examples synthetic or sanitized and do not attach credentials, cookies, private exports, or account data.
